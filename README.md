# Analisis Efisiensi Promo dan Retensi Pengguna Tokopedia

Proyek capstone analisis data ini membahas efektivitas penggunaan voucher promo dan dampaknya terhadap repeat order pengguna baru di Tokopedia dalam jangka waktu 90 hari.

## Ringkasan Singkat

Banyak bisnis e-commerce memberikan promo besar-besaran untuk menarik pengguna baru. Namun, pertanyaan utamanya adalah apakah promo tersebut benar-benar membuat pengguna bertahan dan belanja lagi, atau hanya menghabiskan anggaran?

Melalui analisis terhadap data transaksi, penggunaan voucher, kanal akuisisi, hingga performa pengiriman logistik, proyek ini mengevaluasi mana strategi promo yang efisien dan faktor apa saja yang mempengaruhi keputusan pengguna untuk kembali bertransaksi.

## Temuan Utama

1. **Promo diskon besar tidak menjamin retensi lebih tinggi.**
   Pengguna yang tidak memakai voucher sama sekali memiliki tingkat repeat order 77,5%. Angka ini hampir sama dengan pengguna yang memakai voucher Diskon Persen (76,8%) atau Cashback (76,9%), padahal biaya promo untuk dua jenis voucher tersebut mencapai Rp 110.000 hingga Rp 118.000 per transaksi.

2. **Kanal iklan berbayar (Paid Ads) paling efektif.**
   Iklan berbayar menghasilkan tingkat repeat order tertinggi yaitu 78,8% dengan biaya terukur. Sebaliknya, kanal Referral membutuhkan biaya promo order pertama paling tinggi (Rp 70.505) namun retensinya cenderung lebih rendah (76,7%).

3. **Pengalaman pengiriman mempengaruhi loyalitas.**
   Keterlambatan pengiriman lebih dari 5 hari dari perkiraan SLA menyebabkan penurunan angka repeat order sekitar 4,2%. Selain itu, kendala yang dialami pengguna pada transaksi pertama jika tidak ditangani dengan cepat oleh CS meningkatkan risiko pengguna berhenti menggunakan platform.

## Metrik Utama

- **Total sampel pengguna baru:** 24.938 pengguna
- **Tingkat repeat order 90 hari:** 77,4%
- **Rata-rata nilai belanja pertama:** Rp 985.000
- **Rata-rata biaya promo pertama:** Rp 64.200

## Rekomendasi

- **Alihkan anggaran:** Pindahkan alokasi dari voucher diskon/cashback bernilai tinggi ke voucher Bebas Ongkir yang terbukti lebih disukai dan efisien.
- **Fokus akuisisi:** Utamakan anggaran akuisisi pada kanal Paid Ads yang terbukti menghasilkan pengguna aktif secara berkelanjutan.
- **Audit operasional:** Perketat pengawasan SLA pengiriman pada mitra logistik untuk menjaga kualitas pengalaman transaksi pertama pengguna.
